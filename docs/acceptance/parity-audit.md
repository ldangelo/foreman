## How this audit was done

- **Shipped behaviour** = anchors re-derived by `grep -n` at `126ff019` (not copied from the old audit) plus the merged PR.
  Path shorthand used below: `S/` = `packages/foreman_server/lib/foreman_server/`, `W/` = `packages/foreman_server/lib/foreman_server_web/`,
  `T/` = `packages/foreman_server/test/foreman_server/`, `TW/` = `packages/foreman_server/test/foreman_server_web/`,
  `CFG/` = `packages/foreman_server/config/`, `CLI/` = `packages/foreman_cli/cmd/foreman/`. A bare `tools.ex` is `S/mcp/tools.ex` and a bare
  `run_executor.ex` is `S/workflow/run_executor.ex` (each is the only file of that name); a bare test name in the Tests column sits in the
  directory of the path before it.
- **Automated tests** = test files that were opened and whose assertions name the behaviour. Nothing was executed in this audit:
  "covered" means "a test exists that would fail if it broke", not "CI is green" (CI status of `main` is separate).
- **Live evidence** = what the committed acceptance documents record, quoted, never re-run here. Abbreviations:
  **ACC** `claude-projects-live-run.md` (first manual run, pi, faked `gh`), **ACC2** `claude-projects-acceptance-2026-10-22.md`
  (`claude_projects_flow.sh` + `failure_injection.sh`, pi), **GH** `github-live-run.md` (real private GitHub repo, scripted stage 8),
  **LV** `parity-gaps-live-run.md` (real `claude` haiku + pi), **LS** `live-steering-live-run.md`, **IA** `inflight-approvals-live-run.md`,
  **PRB** `pr-actions-live-view.md`, **REV** `review-*.md`, **CF** `coordinator-crash-turn-fence-live-run.md`,
  **CPM** `claude-phase-model-pin-live-run.md` (all under `docs/acceptance/`); **MR** `docs/lessons/multi-repo-e2e-2026-10-21.md` and
  **UIA** `docs/lessons/ui-a11y-report-2026-10-22.md`. Providers: pi on `minimax/MiniMax-M2.7-highspeed` carries almost everything;
  `claude` (haiku) only where LV/IA/LS/REV/CPM say so.
- **Closed-bead cross-check** (S9-T2): all 123 story and spike beads of E0-E16 were re-read against the tree (section below).

Verdicts: **DONE** every behaviour the capability names ships, is tested and has live evidence (accepted live gaps are listed);
**PARTIAL** a named behaviour is absent, or ships with no test, or depends on an external system only ever exercised with fakes;
**MISSING** nothing ships; **DEFERRED (by user)** consciously out of scope.
