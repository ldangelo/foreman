**(1) What it does** — `ForemanServerWeb.Workspace.Refresh` is the coalesced, subscription-driven refresh shared by workspace LiveViews. A connected view subscribes once to `ProjectionStore` (live events only, no replay). Every relevant projection event marks the view dirty; the first dirty event arms a single timer and later events in the window only set the flag, so N events cost one refresh. No periodic timer — an idle project does zero work. It also mints an idempotency `intent` (random session base + refresh count) so repeated clicks dedupe until a refresh advances state.

**(2) Timers/messages armed** — one message: `:workspace_refresh`, armed via `Process.send_after(self(), :workspace_refresh, coalesce_ms())`. `coalesce_ms` = `config :foreman_server, :workspace, coalesce_ms:` (default 250). It also receives (does not arm) `{:projection_event, event}` from the subscription, and emits `[:foreman_server, :workspace, :refresh]` telemetry on each refresh.

**(3) Events ignored** — events whose `event_type` starts with `"Worker"` (`@ignored_prefixes` — worker output carries no state the workspace shows), and events belonging to a different project (`:project_id` mismatch). Events naming no project (e.g. run events, `project_id` nil) are treated as relevant to every workspace. Any event shape other than the three recognized ones (`%EventData{}`, `%RecordedEvent{}`, applied `%{event_type:, payload:}` maps) raises rather than being silently ignored or guessed.
