The worklow should perform the following functions.

** Checkout the PR into a worktree
** Run the build
*** Verify the build is clean (no errors or warnings)
** Verify all tests pass

*** Integration Tests
*** E2E Tests
*** Playright Tests
*** Failing tests should be identified and the PR should be marked 'Changes Requested' with reasoning.
** Verify Code Review Findings are clean
*** Any findings should be addressed
*** Update the PR
** Verify Documentation has been updated

The PR types should map to workflows

** opened

Should map to a workflow that waits for CI results, ensures they are green, checks that documentation has been provided, test coverage hasn't slipped, etc...
It should add comments on the PR which will then get dispatched via the 'edited' hook.

If All checks pass it should merge the PR.

** edited

Should call fix-issue with each successive comment added to the PR by the open hook.
When done it should stack changes onto the existing PR which should trigger the 'syncronize' hook.

** Syncronize

Should map to the same workflow as the opened type.
